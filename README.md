# Lumi

A clean, ad-free reader for manga, comics, and books — built with Kotlin and Jetpack Compose.

## Features

- **Formats**: CBZ, CBR, EPUB, PDF
- **Library**: scans any folder you choose, auto-categorizes by parent folder, groups volumes into series
- **Reader modes**: paged, vertical webtoon, reflowable EPUB
- **Polished UI**: Netflix-style home with Continue Reading and Recently Added
- **Offline-first**: nothing leaves your device, no accounts, no tracking, no ads
- **Themes**: light, dark, and Material You

## Install

Download the latest APK from [Releases](../../releases/latest).

## Requirements

Android 8.0 (API 26) or newer.

## Built with

- Kotlin + Jetpack Compose
- Hilt, Room, DataStore
- Coil, Material 3
